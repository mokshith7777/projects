# TIMEJ

TIMEJ is a JARVIS Android timekeeping experience built around a mechanical flip-clock aesthetic and focused utility.

## What the experience offers
- **Mechanical Flip Clock:** a high-contrast, split-flap-inspired clock presentation for quick time awareness.
- **Stopwatch:** measure elapsed time with dedicated start, pause and reset controls.
- **Countdown Timer:** set a duration and keep the remaining time visible, with completion alert support in the app.
- **Pomodoro Focus:** structure work into focused intervals and planned breaks.
- **Android-first product experience:** a dedicated mobile application with a focused visual identity.

## Product details
- Release label: v5.0

## Privacy and security
No API keys, access tokens, private endpoints, signing credentials or personal contact secrets belong in this public website. Any credential that has appeared in a public commit must be rotated at its provider; deleting it from the latest file does not erase Git history.

## Distribution and support
- The website points to the latest GitHub Release asset named `TimeJ.apk`.
- Release metadata and asset download totals are read from GitHub's public Releases API. Totals represent asset downloads, not unique users.
- UPI support uses a client-side UPI intent and QR code. Configure `payment-config.js` only with a valid UPI ID and payee name belonging to an adult account holder/guardian. These values are public on the website; never put payment secrets or UPI PINs here.
- The site does not verify UPI transactions and does not automatically unlock paid features. Verify payments independently before granting anything.
- International checkout remains hidden until a valid HTTPS checkout URL is configured.
- The Android APK itself must be attached manually to a GitHub Release as `TimeJ.apk`; the website cannot create a release asset without the APK binary.
